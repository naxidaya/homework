## 必修二 第九章《统计》

```
第九章 统计
│
├─ 9.1 随机抽样
│  ├─ ① 统计基本概念
│  │   ├─ 总体：调查对象的全体，如全校学生身高值构成总体
│  │   ├─ 个体：总体中每一个调查对象，即每位学生的一个身高
│  │   ├─ 样本：从总体中抽出的部分个体，如抽出的100名身高
│  │   └─ 样本量：样本中包含的个体数目，上例即 100
│  ├─ ② 调查方式
│  │   ├─ 普查(全面调查)：逐一调查每个个体，数据准确但工作量大、成本高
│  │   └─ 抽样调查：抽部分个体估计总体，省时省力成本低，实际最常用
│  ├─ ③ 简单随机抽样
│  │   ├─ 定义：从含 N 个体的总体中逐个不放回抽 n 个，每个个体入样概率相等(n/N)
│  │   ├─ 方法A 抽签法：编号制签、搅拌均匀后抽取，适合总体少
│  │   ├─ 方法B 随机数法：用随机数表或计算机产生随机数抽取，可处理较大样本
│  │   └─ 适用：总体个体数较少、各部分特征差异不大
│  └─ ④ 分层随机抽样
│      ├─ 定义：按特征把总体分成互不重叠的层，各层按比例独立抽取
│      ├─ 分配：第 k 层抽 nₖ = Nₖ × n/N 个，与该层个体数成正比
│      ├─ 优点：利用分层信息，样本更有代表性、误差更小
│      └─ 适用：总体由差异明显的几部分构成（如按年龄/地域/性别分层）
│      ※ 两种抽样共同点：都保证每个个体入样概率相等（公平性）
│
├─ 9.2 用样本估计总体
│  ├─ ① 频率分布
│  │   ├─ 频率 = 频数 ÷ 样本量，表示该区间数据出现的比例
│  │   ├─ 频率分布表：按组距分组，统计各组的频数与频率
│  │   ├─ 直方图：纵轴为“频率÷组距”，小矩形面积=该组频率，总面积=1
│  │   └─ 折线图：连接各小矩形上边中点，反映数据分布走势
│  ├─ ② 百分位数
│  │   ├─ 定义：累计频率达 p% 时对应值，即有 p% 不超过它
│  │   ├─ 常用：第一四分位数(25%)、中位数(50%)、第三四分位数(75%)
│  │   └─ 中位数抗极端值，比平均数更能代表“中间水平”
│  ├─ ③ 集中趋势（平均水平）
│  │   ├─ 平均数 x̄ = 数据之和÷个数，对极端值敏感
│  │   ├─ 中位数：排序后中间位置值，不受极端值影响
│  │   └─ 众数：出现次数最多的数据
│  ├─ ④ 离散程度（波动大小）
│  │   ├─ 极差 = 最大值 − 最小值，简单但只用两端数据
│  │   ├─ 方差：各数据离均差平方的平均，越大越分散
│  │   └─ 标准差 = 方差的平方根，更常用
│  └─ ⑤ 总体估计
│      └─ 用样本的频率分布、平均数、标准差估计总体；样本越大越可靠
│
└─ 9.3 统计案例
   └─ 流程：设计抽样方案→收集数据→整理图表→计算特征数→下结论
```

## 必修二 第十章《概率》

```
第十章 概率
│
├─ 10.1 随机事件与概率
│  ├─ ① 随机试验/样本空间
│  │   ├─ 随机试验：可重复、结果不确定
│  │   ├─ 样本点：试验的每一种可能结果
│  │   └─ 样本空间Ω：全部样本点的集合
│  ├─ ② 事件类型
│  │   ├─ 随机事件：可发生可不发生，是样本空间的子集
│  │   ├─ 必然事件：一定会发生，= Ω
│  │   └─ 不可能事件：一定不会发生，= ∅
│  ├─ ③ 关系与运算
│  │   ├─ 包含 A⊆B：A 发生则 B 必发生
│  │   ├─ 并事件 A∪B：至少一个发生
│  │   ├─ 交事件 A∩B：同时发生
│  │   ├─ 互斥事件：不能同时发生（A∩B=∅）
│  │   ├─ 对立事件：恰好一个发生，A∪Ā=Ω 且 A∩Ā=∅
│  │   └─ 注意：对立必互斥，但互斥不一定对立
│  ├─ ④ 古典概型
│  │   ├─ 条件①样本点有限
│  │   ├─ 条件②每个样本点等可能
│  │   └─ 公式：P(A) = n(A)/n(Ω)
│  └─ ⑤ 概率性质
│      ├─ 0≤P(A)≤1，P(Ω)=1、P(∅)=0
│      ├─ 互斥：P(A∪B)=P(A)+P(B)
│      ├─ 对立：P(Ā)=1−P(A)
│      └─ 一般加法：P(A∪B)=P(A)+P(B)−P(A∩B)
│
├─ 10.2 事件的相互独立
│  ├─ 定义：A 不影响 B 的概率，P(A∩B)=P(A)·P(B)
│  ├─ 判定：验证乘积公式是否成立
│  ├─ 性质：Ā与B、A与B̄、Ā与B̄ 也独立
│  └─ 应用：多个独立事件相乘；“至少”用 1−全不发
│
└─ 10.3 频率与概率
   ├─ 频率 = 频数÷试验次数，随机波动
   ├─ 概率：客观稳定的确定值
   ├─ 关系：试验次数多，频率趋近概率
   └─ 应用：用大量试验的频率估计概率
```

## 选择性必修一 第二章《直线与圆的方程》

```
第二章 直线与圆的方程
│
├─ 2.1 直线的倾斜角与斜率
│  ├─ 倾斜角 α
│  │   ├─ 定义：直线向上的方向与 x 轴正方向所成的最小正角
│  │   └─ 范围：0° ≤ α < 180°；α=0° 时直线与 x 轴平行或重合
│  ├─ 斜率 k
│  │   ├─ 定义：k = tan α（α≠90° 时存在）
│  │   ├─ 过两点 P₁(x₁,y₁)、P₂(x₂,y₂)：k = (y₂−y₁)/(x₂−x₁)，x₁≠x₂
│  │   ├─ 特别：x₁=x₂ 时直线垂直 x 轴，斜率不存在
│  │   └─ 关系：α 为锐角 k>0，α 为钝角 k<0，α=90° 无斜率
│  └─ 两直线平行/垂直(斜率存在时)
│      ├─ 平行：k₁ = k₂
│      └─ 垂直：k₁·k₂ = −1
│
├─ 2.2 直线的方程
│  ├─ ① 点斜式
│  │   ├─ y − y₀ = k(x − x₀)（已知一点(x₀,y₀)和斜率 k；不能表示铅直的直线）
│  │   └─ 特例：斜截式 y = kx + b（b 为纵截距）
│  ├─ ② 两点式
│  │   └─ (y−y₁)/(y₂−y₁) = (x−x₁)/(x₂−x₁)，x₁≠x₂ 且 y₁≠y₂
│  ├─ ③ 截距式
│  │   └─ x/a + y/b = 1，a、b 分别表示 x 轴、y 轴非零截距
│  └─ ④ 一般式
│      ├─ Ax + By + C = 0（A、B 不全为 0）
│      ├─ A=0 时→与 x 轴平行；B=0 时→与 y 轴平行；C=0 时→过原点
│      └─ 各种形式都可化为一般式
│
├─ 2.3 直线的交点与距离
│  ├─ 交点坐标：联立两直线方程解方程组
│  ├─ 两点间距离
│  │   └─ |P₁P₂| = √[(x₂−x₁)² + (y₂−y₁)²]
│  ├─ 点到直线距离
│  │   └─ d = |Ax₀+By₀+C| / √(A²+B²)
│  └─ 两平行线间距离
│      └─ d = |C₁−C₂| / √(A²+B²)
│
├─ 2.4 圆的方程
│  ├─ 标准式
│  │   └─ (x−a)² + (y−b)² = r²，圆心(a,b)，半径 r；原点 x²+y²=r²
│  └─ 一般式
│      └─ x²+y²+Dx+Ey+F=0，须 D²+E²−4F>0
│          ├─ 圆心(−D/2, −E/2)
│          └─ 半径 r = ½√(D²+E²−4F)
│
└─ 2.5 直线与圆、圆与圆的位置
   ├─ 直线与圆
   │   ├─ 几何法：圆心到直线距离 d 与 r 比
   │   │   ├─ d<r：相交；d=r：相切；d>r：相离
   │   └─ 代数法：联立方程看判别式 Δ
   │       ├─ Δ>0 相交；Δ=0 相切；Δ<0 相离
   └─ 圆与圆
       └─ 用圆心距 d 与 R、r 比较
           ├─ d>R+r 外离；d=R+r 外切
           ├─ R−r<d<R+r 相交
           ├─ d=R−r 内切；d<R−r 内含
           └─ 同心圆属于内含
```

## 选择性必修一 第三章《圆锥曲线的方程》

```
第三章 圆锥曲线的方程
│
├─ 3.1 椭圆
│  ├─ 定义
│  │   └─ 到两定点 F₁、F₂ 距离之和为常数 2a，且 2a>2c
│  ├─ 标准方程
│  │   ├─ 焦点在 x 轴：x²/a² + y²/b² = 1（a>b）
│  │   └─ 焦点在 y 轴：y²/a² + x²/b² = 1（a>b）
│  │       └─ 关系：a² = b² + c²
│  ├─ 几何性质
│  │   ├─ 长轴 2a、短轴 2b、焦距 2c
│  │   ├─ 顶点 ±a、±b；焦点 ±c
│  │   └─ 离心率 e = c/a（0<e<1，越接近 1 越扁）
│  └─ 焦半径（延伸）
│       └─ 椭圆上点 P 到两焦点距离和恒为 2a
│
├─ 3.2 双曲线
│  ├─ 定义
│  │   └─ 到两焦点距离之差绝对值等于常数 2a（0<2a<2c）
│  ├─ 标准方程
│  │   ├─ 焦点在 x 轴：x²/a² − y²/b² = 1
│  │   └─ 焦点在 y 轴：y²/a² − x²/b² = 1
│  │       └─ 关系：c² = a² + b²（与椭圆相反）
│  ├─ 渐近线
│  │   ├─ x 轴型：y = ±(b/a)x
│  │   └─ y 轴型：y = ±(a/b)x
│  └─ 性质
│      ├─ 实轴 2a、虚轴 2b、焦距 2c
│      ├─ 离心率 e = c/a（e>1）
│      ├─ 等轴双曲线：a=b，渐近线 y=±x，e=√2
│      └─ 焦点三角形：||PF₁|−|PF₂|| = 2a
│
└─ 3.3 抛物线
   ├─ 定义
   │   └─ 到定点 F 与到定直线 l（准线）距离相等的点的轨迹，离心率恒为 1
   ├─ 四种标准方程
   │   ├─ y²=2px：焦点(p/2,0)、准线 x=−p/2，开口右
   │   ├─ y²=−2px：焦点(−p/2,0)、准线 x=p/2，开口左
   │   ├─ x²=2py：焦点(0,p/2)、准线 y=−p/2，开口上
   │   └─ x²=−2py：焦点(0,−p/2)、准线 y=p/2，开口下
   └─ 通径与焦半径
      ├─ 通径长 2p
      └─ 焦半径：y²=2px 上点 P(x₀,y₀) 到焦点距 = p + x₀ 即准线距 x₀+p/2
```
